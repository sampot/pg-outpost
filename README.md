# 離島前哨 (`pg-outpost`)

殖民者需求、心情、生產鏈經營小品。

## 遊玩

純 HTML／CSS／JavaScript（無 build）。在 Playgrounds 畫布或 go 純玩模式開啟。

**目標：** 派工維持飽足／休息／社交，沿 **營地 → 倉庫 → 工坊 → 信標塔** 完成生產鏈，在第 18 日後點亮信標且士氣達標即勝；斷糧、士氣潰散或殖民者離島則敗。

**操作：** 點殖民者 → 點工作站派工 → 「結束這一天」推進；資源足夠時可「建造下一階」。

```bash
npx vitest run
```
